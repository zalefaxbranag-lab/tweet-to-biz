# Prompts images — landing page couples

Chaque bloc est **complet et autonome** : copie-le tel quel dans ton
generateur, rien a ajouter. C'est mot pour mot ce que `tools/kie.py`
envoie, donc le fichier et le script ne peuvent pas diverger.

Pour les generer via KIE depuis ta machine :

```bash
cd craftstory-couples/tools
python3 kie.py cards      # les 6 cartes     ~108 credits
python3 kie.py faces      # les 5 visages     ~90 credits
python3 kie.py banner     # le fond, x2       ~36 credits
```
